# ModScanner

Античит-сканер модов Minecraft (Fabric 1.21+, также 26.x и NeoForge). Разбирает `.jar` полностью —
байт-код, Mixin-инъекции, строки (включая зашифрованные) — и сверяет файлы с Modrinth.

**Обнаружение:** KillAura, TriggerBot, HitBox, Reach, AimAssist, внешняя авторизация, загрузка кода
с сервера, FakeLag / Blink, PingSpoof, задержка входящих пакетов, скачивание и запуск файлов, кража
данных, кража токена сессии, отправка на Discord-вебхук.

## Использование

Запустите `ModScanner.exe` и выберите папку с модами, проверьте папку программы или перетащите
папку / `.jar` в окно. После проверки — «Открыть отчёт».

Консольный режим:

```
ModScanner.exe [файлы и папки…] [--offline] [--out DIR] [--cache DIR] [--open] [--nowait]
```

Коды возврата: `0` — чисто, `1` — есть читы/подозрительные, `2` — нет файлов, `3` — ошибка.

## Отчёт

- `modscan-<время>.html` — сводка по всем файлам;
- `modscan-<время>/…html` — подробный отчёт по каждому моду (доказательства: класс, метод, цепочка
  вызовов, API игры);
- `modscan-<время>.json` — результаты для автоматизации.

## Сборка

```bash
dotnet publish src/ModScanner -c Release -r win-x64 -o dist
```

Результат — `dist/ModScanner.exe` (single-file, self-contained, .NET не требуется).
